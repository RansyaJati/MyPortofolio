# Implementation Plan

## Phase 0 --- Setup

-   Buat Next.js App Router + TypeScript.
-   Konfigurasikan Tailwind.
-   Pasang Motion dan Lucide React.
-   Siapkan linting, folder, font, dan CSS variables.

Selesai jika project berjalan tanpa error dan token desain tersedia.

## Phase 1 --- Design foundation

-   Container, grid, spacing, typography.
-   Fixed navbar dan active section indicator.
-   Mobile navigation.
-   Focus states.

Selesai jika navigasi desktop/mobile bekerja dan layout konsisten.

## Phase 2 --- Hero and Technical

-   Hero.
-   Profile.
-   Tech stack groups.
-   Project cards.
-   Masukkan data/aset yang telah dikonfirmasi; gunakan placeholder
    jelas untuk sisanya.

Selesai jika konten terbaca dan screenshot tidak menyebabkan layout
shift.

## Phase 3 --- Creative

-   Dark theme.
-   Experimental editorial gallery.
-   Artwork hover/focus reveal.
-   Blender animation gallery dengan poster dan video preview.
-   Touch fallback.

Selesai jika gallery berfungsi di desktop/mobile dan video tidak
autoplay massal.

## Phase 4 --- Unified ending

-   About dan Connect.
-   Kembali ke light theme.
-   Satukan narasi Technical dan Creative.
-   Footer.

Selesai jika penutup terasa sebagai satu identitas personal.

## Phase 5 --- Polish

-   Responsive checks.
-   Keyboard/accessibility.
-   Reduced motion.
-   Optimasi gambar/video.
-   SEO metadata.
-   Broken links, console, typecheck, lint, build.

## Urutan prioritas

1.  Struktur dan konten.
2.  Visual hierarchy.
3.  Responsive behavior.
4.  Interaksi dasar.
5.  Motion dan polish.

## Out of scope untuk versi awal

CMS/admin, authentication, database, blog engine, Three.js/WebGL,
analytics kompleks. Tambahkan hanya jika kebutuhan nyata muncul.
