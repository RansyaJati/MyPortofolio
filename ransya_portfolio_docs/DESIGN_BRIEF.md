# Design Brief

## Design direction

**Modern Editorial Minimalism --- Dual Identity with Unified Ending.**

Fondasi visual menggunakan editorial minimalism dan Swiss-inspired
typography. Technical dibuat terstruktur; Creative lebih ekspresif;
bagian akhir menyatukan keduanya.

## Technical --- Structured Editorial

Karakter: light, rapi, informatif, grid konsisten, screenshot aplikasi
menjadi fokus.

Warna: - Background `#F8F8F8` - Primary text `#171717` - Secondary text
`#777777` - Border `#DEDEDE` - Accent opsional `#6C63FF` (gunakan hemat)

Konten: profile singkat, tech stack terkelompok, selected projects,
kontribusi, fitur, screenshot, status, repository/demo bila tersedia.

## Creative --- Experimental Editorial

Karakter: dark, gallery dengan ukuran bervariasi, komposisi sedikit
asimetris, visual karya menjadi fokus, hover reveal, video preview
Blender.

Warna: - Background `#111111` - Primary text `#F5F5F5` - Secondary text
`#999999` - Border `#333333`

Pisahkan Graphic Design/Artwork dan 3D Animation karena kebutuhan
presentasinya berbeda.

## Unified Ending

About dan Connect kembali ke light theme. Bagian ini menyatukan software
development dan kreativitas sebagai dua sisi dari satu identitas
personal.

## Typography

-   Heading: Jakarta Sans.
-   Body: Inter atau Jakarta Sans.
-   Maksimal dua keluarga font.
-   Gunakan hierarki ukuran, weight, line-height, dan spacing.
-   Gunakan `next/font`.

## Layout

-   Container dan grid konsisten.
-   Whitespace cukup.
-   Border tipis lebih diutamakan daripada shadow berat.
-   Radius kecil atau sudut tegas.
-   Jangan menjadikan setiap elemen sebagai card.
-   Responsive untuk desktop, tablet, dan mobile.

## Hero

Headline besar sebagai fokus utama, ditambah deskripsi singkat, CTA
menuju Technical/Creative, dan supporting visual kecil. Foto, ilustrasi,
maskot, atau elemen abstrak masih perlu dipilih.

Copy sementara: **DESIGNING & BUILDING DIGITAL EXPERIENCES**. Jangan
anggap sebagai copy final.

## Navigation

Fixed navbar; nama/wordmark di kiri, anchor links di kanan. Active
section ditandai secara halus. Navbar menyesuaikan tema section aktif.
Mobile memakai menu ringkas.

## Accessibility

Kontras memadai, keyboard focus terlihat, semantic HTML, alt text,
alternatif untuk hover pada touch device, dan hormati
`prefers-reduced-motion`.
