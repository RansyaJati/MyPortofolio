# Ransya --- Personal Portfolio

Dokumentasi spesifikasi untuk website portofolio personal Ransya
Maulana.

## Konsep

**Dual Identity with Unified Ending**: satu website dengan dua
pengalaman visual---Technical (light, structured editorial) dan Creative
(dark, experimental editorial)---yang bertemu kembali pada About dan
Connect.

## Keputusan desain

-   Fixed navbar.
-   Hero menggabungkan typography besar dan supporting visual kecil.
-   Technical: light theme, Structured Editorial.
-   Creative: dark theme, Experimental Editorial.
-   About/Connect: kembali ke light theme dan menyatukan kedua
    identitas.
-   Perubahan tema berlangsung smooth saat scrolling, bukan perpindahan
    halaman.

## Dokumen

-   `DESIGN_BRIEF.md`: art direction, warna, typography, layout.
-   `INFORMATION_ARCHITECTURE.md`: struktur section dan konten.
-   `TECHNICAL_ARCHITECTURE.md`: stack, folder, rendering, media, SEO.
-   `CONTENT_MODEL.md`: struktur data project, artwork, animasi.
-   `INTERACTION_SPEC.md`: navbar, hover, video, transisi.
-   `IMPLEMENTATION_PLAN.md`: fase pengerjaan dan acceptance criteria.
-   `AGENT_GUIDELINES.md`: instruksi untuk AI coding agent.

## Prinsip

-   Jangan mengarang skill, pengalaman, project, pencapaian, statistik,
    atau tautan.
-   Gunakan placeholder untuk informasi yang belum dikonfirmasi.
-   Prioritaskan performa, accessibility, responsive design, dan
    maintainability.
-   Jangan menambahkan backend/CMS/database sebelum diperlukan.
